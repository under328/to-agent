## 如何开工（三步）

1. 打开当日（或任意未完成）的任务卡；
2. 对 ZCode 说：「**按 W1-D1 任务卡开工**」——我会陪你结对写代码；
3. 完成卡内「今日验收」打勾 → 做 5 道自测题 → 在 journal/README.md 当周记录一行。

# to-agent — 同往 AGI 之路

> 1998 年生 · 武汉 · 前端工程师（Vue / 鸿蒙）的 AI 转型学习仓库。
> 由 ZCode（GLM）自动维护：每日课程生成、周复盘、计划修订均在此提交。

## 这是什么

在 AI 替代「开发任务」的时代，把「写页面的前端」升级为「用 AI 交付产品、并且会构建 AI 产品」的工程师的完整训练基地：

- **目标**：12 个月内转型 AI 应用工程师（LLM 应用 / RAG 方向），产线 2 个上线的 AI 作品 + 技术文章；
- **约束**：每周学习时间 ≤ 5 小时，Agent 内容利用上班碎片时间学习，晚间（GLM 免费窗口 23:00~09:00）承载其余；
- **方法论**：输出 ≥ 输入，读懂才算完成，一次只有一个项目。

## 目录结构

| 文件/目录 | 说明 |
| --- | --- |
| `profile.md` | 个人档案：背景、技术栈、发展意愿（AI 会话的上下文基础） |
| `plan.md` | 12 个月发展计划：形势判断、战略、阶段行动、每周节奏、里程碑、风险 |
| `curriculum.md` | 阶段一 12 周课程表：每周学什么、产出什么、自检标准 |
| `lessons/` | 每日学习材料（工作日早 7:00 由定时任务自动生成） |
| `journal/` | 学习日志与每周复盘（周日 23:05 自动生成） |
| `projects/` | 实战作品代码（作品 1：AI 周报生成器；作品 2：AI 笔记） |

## 运行机制

1. **每晚 23:00**：ZCode 定时任务批量生成并优化未来数日课程到 `lessons/`；
2. **早晨 08:10~09:00**：学当日材料 + 做 5 道自测题；
3. **周末半天**：完成当周作品产出，ZCode 结对编程 + Code Review；
4. **周日 23:05**：ZCode 定时任务生成本周复盘 + 下周三件事。
